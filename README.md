## ⭐ Featured Projects

### 🧠 Anbarchi — AI Inventory Manager

An inventory management platform designed to help cafés and restaurants monitor inventory and predict future material shortages.

The idea originated from a real business problem: reducing the operational burden of constantly monitoring inventory and deciding when materials need to be replenished.

The system analyzes consumption behavior and inventory data to move toward predicting **what will run out, when it will run out, and when it should be replenished**.

#### Architecture

* pnpm Workspace Monorepo
* React + Vite
* Express + TypeScript
* PostgreSQL
* Drizzle ORM
* TailwindCSS
* shadcn/ui
* RESTful APIs
* OpenAPI
* Orval
* JWT Authentication

#### Key Technical Challenges

* Automated inventory consumption calculation
* Processing daily sales data through CSV imports
* Inventory threshold and alert management
* Multi-tenant architecture
* Maintaining consistency between frontend and backend APIs
* Designing shared packages across the monorepo

### 🎓 Learning Management System

A full-stack Learning Management System developed as my bachelor's final project.

The platform is designed around three primary roles:

* **Admin** — manages the educational organization
* **Instructor** — creates and manages courses
* **Student** — purchases and studies courses

#### Features

* Course management
* Student enrollment
* Instructor management
* Assessments and quizzes
* Student progress tracking
* Certificate generation
* Real-time notifications
* Role-based access control

#### Architecture

* React
* Vite
* Express.js
* PostgreSQL
* JWT Authentication
* Socket.io
* TailwindCSS
* RESTful API

#### Key Technical Challenge

During development, the project had to migrate from Prisma ORM to direct PostgreSQL queries using `pg` due to deployment and network limitations.

This required redesigning the data access layer and rewriting complex queries for features such as student progress calculation, assessments, relational data retrieval, and certificate generation.
